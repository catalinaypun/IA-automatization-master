Components › Tooltip

Tooltip

An overlay that clarifies another component or content element. Triggered on hover or focus of the info icon.

Positions & Alignments

Above · Center Default position. The tooltip appears above the trigger, aligned to its center.
Above / Center
Above · Left The popup aligns its left edge with the trigger's left edge.
Above / Left
Above · Right The popup aligns its right edge with the trigger's right edge.
Above / Right
Below · Center The tooltip appears below the trigger when space above is limited.
Below / Center
Body only — no title. Use when the context is already clear and a label would be redundant.

AI Prompts › Vibe Coding

Vibe Coding Prompts

System prompts for AI-assisted UI development. Choose based on whether your tool can load external CSS.

Which prompt should I use?

Tool Use prompt Reason
Claude Prompt A Supports external CSS links in output
Cursor / Windsurf Prompt A Can reference remote stylesheets
Bolt / Lovable / v0 Prompt A Renders HTML with linked CSS
Gemini Prompt B Cannot load external URLs in output
ChatGPT Prompt B No external stylesheet support
Copilot Chat Prompt B Inline styles only
🔗

For Claude, Cursor, Windsurf, Bolt, Lovable, v0. The stylesheet loads remotely — component styles are always in sync with the latest version of the design system. Paste this at the start of each session or set it as the project's system prompt.

System Prompt · Prompt A 
You are building UI for a Verizon internal tool using the VDS design system.

## RULE 1 — Always link the stylesheet

Every HTML file you generate MUST include this in the <head>:
<link rel="stylesheet" href="https://catalinaypun.github.io/verizon-design-system/design-system.css">

This file contains all CSS custom properties and component classes.
Never duplicate or override it.
