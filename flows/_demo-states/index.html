How the state switcher works

Use the States toolbar (bottom-right) to switch between states without a page reload. Each state updates the URL param (?state=…) so it can be deep-linked. Add ?presenter=true to hide the toolbar for clean demos.

?state=default ?state=error ?state=empty ?state=default&presenter=true
